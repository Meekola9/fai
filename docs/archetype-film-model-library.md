# FAI Archetype Film Model Library

This library maps every current FAI archetype ID to professional and college film models. The comparisons are teaching references—not claims that testing alone proves technique, instincts, production, or football IQ.

## How to use the library

- **Professional model:** shows the mature version of the role.
- **College film model:** provides a second, often more developmentally accessible example.
- **Study focus:** tells the athlete what to watch instead of merely watching highlights.
- Use full-game or all-snaps film whenever possible. Confirm the FAI athletic profile with position-specific film before treating an archetype as final.

## Film-room implementation requirements

Each future in-app film record should preserve this structure:

```ts
interface ArchetypeFilmModel {
  archetypeId: string
  playerName: string
  level: 'NFL' | 'College' | 'Historical'
  fitTier: 'primary' | 'trait' | 'body-type' | 'development'
  studyTopics: string[]
  sourceUrl?: string
  clipStartSec?: number
  clipEndSec?: number
  coachNote?: string
  verified: boolean
}
```

### Guardrails

1. Do not automatically label a player from film-model similarity alone.
2. Do not use highlights as the only evidence for processing, blocking, coverage, or consistency.
3. Keep the athlete's FAI archetype ID unchanged; film confirms or challenges the projection.
4. Permit multiple models for one archetype and multiple archetypes for one player.
5. Store exact timestamps and coaching notes so athletes reach the teaching point immediately.
6. Prefer legally embeddable or coach-owned film links; never imply FAI owns third-party footage.
